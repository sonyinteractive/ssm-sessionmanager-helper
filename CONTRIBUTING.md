# Contributing to ssm-sessionmanager-helper

Thank you for your interest in contributing!

## Before You Start

All contributors must sign the [Sony Interactive Entertainment Contributor License Agreement](https://github.com/sonyinteractive/sie-ospo-cla) before
we can accept a pull request. The CLA bot will prompt you automatically on your first PR.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes and ensure all tests pass
4. Push to your fork and open a Pull Request against `main`

## Development Setup

```sh
git clone https://github.com/sonyinteractive/ssm-sessionmanager-helper.git
cd ssm-sessionmanager-helper

# Follow the installation instructions [here](README.md)
```

## Code Style

- Follow the existing conventions in the repository
- Run the formatter/linter before submitting a PR
- All new code should have corresponding tests

## Reporting Issues

- Use [GitHub Issues](https://github.com/sonyinteractive/ssm-sessionmanager-helper/issues)
- Search for existing issues before opening a new one
- Include steps to reproduce, expected vs. actual behavior, and relevant logs

## Pull Request Guidelines

- Keep PRs focused on a single change
- Write a clear description explaining what changed and why
- Link any related issues
- Ensure CI passes before requesting review
